## Open source nədir?

**Açıq mənbəli (open source) alətlər** — mənbə kodu açıq olan, yəni hər kəsin istifadə edə və dəyişdirə biləcəyi proqram təminatıdır. Python və R məhz belə alətlərdir.

Nəyə görə şirkətlər open source alətlərə üstünlük verir?

- **Xərclərin azalması** — alətlər ödənişsizdir. Şirkət lisenziya xərclərindən qurtulur və büdcəni optimallaşdırır.
- **Geniş funksionallıq** — Python və R-in zəngin kitabxanaları məlumat təhlili üçün geniş imkanlar yaradır.
- **İcma dəstəyi** — böyük və aktiv icmalar daimi yeniliklər və dəstək təmin edir.
- **Çeviklik** — mənbə kodu açıq olduğu üçün qurumlar aləti öz ehtiyaclarına uyğunlaşdıra bilir.

## Nəyə görə Python?

Python — statistik analiz, vizuallaşdırma və məlumat elmi üçün güclü proqramlaşdırma dilidir. Data analitikası və maşın öyrənməsində ən çox istifadə olunan dillərdən biridir.

- **Çox yönlülük** — yalnız statistik analiz yox, həm də veb proqramlaşdırma, avtomatlaşdırma və maşın öyrənməsi.
- **Zəngin paket ekosistemi** — `pandas`, `NumPy`, `matplotlib`, `scikit-learn`, `TensorFlow`.
- **Vizuallaşdırma** — `matplotlib`, `seaborn` və `Plotly` ilə keyfiyyətli və interaktiv qrafiklər.
- **İcma dəstəyi** — sualına cavabı demək olar ki, həmişə tapacaqsan.
- **Sənaye və akademiyada populyarlıq** — həm tədqiqatda, həm də real biznes layihələrində lider dillərdəndir.

## Data analitik üçün iki əsas istiqamət

**Data təmizləmə və emal.** `pandas` kitabxanasının DataFrame-ləri ilə böyük datasetlərdə təmizləmə, filtrləmə və çevirmə əməliyyatları bir neçə sətir kodla icra olunur.

**Vizuallaşdırma.** `matplotlib` və `seaborn` statistik qrafiklər üçün, `Plotly` isə interaktiv qrafiklər üçün istifadə olunur.

> Bu kitabxanalarla növbəti günlərdə tanış olacağıq. Əvvəlcə Python-un özünü — tipləri, strukturları, şərtləri və dövrləri öyrənirik.
