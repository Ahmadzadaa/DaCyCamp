**Python4Business** — biznes və data analitikası üçün Python kursudur. Proqramlaşdırma təcrübəsi tələb olunmur: hər şeyi sıfırdan, addım-addım öyrənəcəyik.

## Tədris formatı

| Bölmə                 | Təfərrüat                                                                      |
| --------------------- | ------------------------------------------------------------------------------ |
| Müddət                | 10 tədris günü                                                                 |
| Gün 1                 | Dərs daxilində təcrübi tapşırıq (qiymətləndirilmir)                            |
| Qiymətləndirmə (~70%) | 3 dərs-daxili və 4 ev tapşırığı                                                |
| Yekun layihə (~30%)   | Gün 8-də elan edilir. Meyarlar: tamlıq 50%, qavrama rahatlığı 25%, müdafiə 25% |
| Layihə müdafiəsi      | Gün 10-dan sonra ~10 gün ərzində                                               |

## Platformada necə öyrənəcəksən

1. **Nəzəri addım** — qısa izah və kod nümunələri. Oxuyub «davam et» düyməsini bas.
2. **Test** — mövzunu nə qədər başa düşdüyünü yoxlayan bir neçə sual.
3. **Praktik tapşırıq** — Python kodu birbaşa brauzerdə işləyir, heç nə quraşdırmaq lazım deyil.
   - **İşə sal** — kodu işlədir və nəticəni konsolda göstərir.
   - **Göndər və davam et** — kodu avtomatik testlərlə yoxlayır. Hamısı keçsə, növbəti addım açılır.
   - Çətinlik çəksən, **İpucu** düyməsindən istifadə et.

> Kodun səhvdirsə, test sənə nəyin gözlənildiyini yazacaq. Səhv etmək öyrənmənin bir hissəsidir — istədiyin qədər yenidən cəhd edə bilərsən.

## Gün 1 və Gün 2-nin mövzuları

- Open source nədir, nəyə görə Python?
- Jupyter Notebook və IDE-lər
- «Spreadsheet»-dən «Console»-a: funksiyalar və operatorlar
- Obyekt əsaslı proqramlaşdırma (OOP), Python skripti və PEP8
- Əsas məlumat tipləri: `int`, `float`, `str`, `bool`
- Məlumat strukturları: `list`, `tuple`, `dict`, `set`
- Şərtlər (`if / elif / else`), funksiyalar və modullar
- Dövrlər: `for`, `while`, `break`, `continue`, `pass`
- İş direktoriyası, Jupyter Markdown, notebook-un HTML/PDF-ə ixracı
- Xətaların idarəsi: `try / except / else / finally`
