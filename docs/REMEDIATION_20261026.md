26 oktyabr 2026, `codex/sql-python-pilot`. Dəyişikliklər yerli iş qovluğundadır; GitHub-a push edilməyib. Mövcud funksiyalar və kurs məlumatları saxlanılıb, işlək baza sıfırlanmayıb.

## Xarici hesabdan asılı olan hissələr

SMTP, xarici backup hədəfi, domen və hosting hesabları verilməyib. Kod və quraşdırma təlimatı hazırdır, amma həqiqi xarici məktub göndərişi, serverdən kənar köçürmə və internetdə yerləşdirmə aktiv kimi göstərilmir. Cari mühitdə yerli poçt, yerli backup və detached supervisor işləyir; systemd yalnız uyğun VPS-də quraşdırılır.

Ölçülər, testlər, bərpa nəticəsi və ekran şəkilləri: [CLASSROOM_QA.md](CLASSROOM_QA.md). Konfiqurasiya: [DOCKERLESS_OPERATIONS.md](DOCKERLESS_OPERATIONS.md).
